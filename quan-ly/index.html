Phần 5 · Chỉ dành cho Admin

Quản Trị Hệ Thống, User & Kết Nối

Phân quyền Supabase (Admin/Chú rể/Cô dâu), Google Sheet Apps Script & GitHub Token
1. Phân quyền User & Đăng nhập (Supabase) Chưa kết nối
  1. Tạo dự án miễn phí tại supabase.com ↗ → vào Authentication → Providers → Email → tắt mục Confirm email rồi bấm Save (để tài khoản Chú rể/Cô dâu đăng nhập được ngay không cần xác minh mail).
  2. Bấm nút bên dưới để copy mã SQL khởi tạo bảng phân quyền → trong Supabase chọn SQL Editor → New query → dán toàn bộ và bấm Run.
  3. Vào Project Settings → API (hoặc Connect) copy Project URL và Publishable / anon public key dán vào 2 ô bên dưới rồi bấm Kết nối Supabase:

Tạo & Phân Quyền Tài Khoản

Tạo tài khoản riêng cho Chú rể (Nhà Trai + Chung) và Cô dâu (Nhà Gái + Chung)

2. Kết nối Google Sheet (Apps Script) Chưa gắn Apps Script

Bảng Google Sheet quản lý khách mời: Mở Google Sheet Quản Lý Khách Mời ↗

  1. Bấm nút bên dưới để copy mã kết nối → mở Google Sheet → Tiện ích mở rộng → Apps Script → dán đè toàn bộ và bấm Lưu.
  2. Bấm Triển khai (Deploy) → Tùy chọn triển khai mới → loại Ứng dụng web, quyền truy cập: Bất kỳ ai (Anyone) → Triển khai.
  3. Dán link https://script.google.com/macros/s/.../exec vào ô dưới rồi bấm Kết nối Sheet:
3. Đồng bộ lên Web (GitHub Pages Token) Lưu trên máy này

Khi Admin kết nối GitHub Token tại đây (và đã bật Supabase), Token sẽ được lưu bảo mật trong bảng app_settings để Chú rể & Cô dâu bấm Lưu là tự đồng bộ lên Web mà không bao giờ thấy Token hay hướng dẫn kỹ thuật.

  1. Bấm Tạo nhanh Token (đã tích sẵn quyền repo) ↗ → kéo xuống cuối bấm Generate token → copy mã ghp_... dán vào ô dưới.

Link dự phòng gửi Cô Dâu (khi chưa dùng Supabase)

Nếu chưa bật đăng nhập Supabase, bạn có thể gửi nhanh link tự đồng bộ tab Nhà Gái qua Zalo. Khi đã bật Supabase, chỉ cần gửi tài khoản Email/Mật khẩu cho Cô dâu & Chú rể!
