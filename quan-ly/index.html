Kết nối Google Sheet (Lưu trữ khách mời) Chưa gắn Apps Script

Bảng Google Sheet của bạn đã được tạo sẵn: Mở Google Sheet Quản Lý Khách Mời ↗

  1. Bấm nút bên dưới để copy sẵn mã kết nối, rồi mở Google Sheet ở trên → chọn Tiện ích mở rộng (Extensions) → Apps Script → dán đè toàn bộ và bấm Lưu.
  2. Bấm Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment) → chọn loại Ứng dụng web (Web app), quyền truy cập: Bất kỳ ai (Anyone) → bấm Triển khai.
  3. Copy đường link https://script.google.com/macros/s/.../exec dán vào ô dưới đây rồi bấm Kết nối Sheet:
Tổng ghi nhận 0 0 riêng · 0 vãng lai
Đã mở thiệp 0 0 chưa mở
Sẽ tham dự 0 ~0 khách dự kiến
Nhà Trai / Gái 0 / 0 0 báo bận

Đồng bộ lên Web & Gửi Cô Dâu tự sửa Lưu trên máy này

Để khi bạn hoặc Cô Dâu bấm Lưu, mọi thay đổi (địa chỉ, giờ, QR, ảnh album) sẽ tự đẩy lên GitHub và cập nhật cho tất cả khách mời trên mọi điện thoại:

  1. Cách nhanh nhất (10 giây — khuyến nghị): Chú rể bấm Tạo nhanh Token (đã tích sẵn quyền repo) ↗ → kéo xuống cuối bấm nút xanh Generate token → copy mã ghp_... dán vào ô dưới.
  2. (Hoặc nếu dùng Fine-grained Token): phải chọn Only select repositories → thiep-cuoi-vannam-kimtien, rồi bấm Add permissions → chọn Contents → đổi sang Read and write.

Gửi link cấu hình riêng cho Cô Dâu

Cô dâu chỉ cần bấm link này trên Zalo → máy tự kết nối sẵn & mở thẳng tab Nhà Gái. Cô dâu sửa địa chỉ, giờ, QR, ảnh rồi bấm Lưu là tự đồng bộ lên GitHub cho mọi khách mời (tự gộp thông minh, không làm mất phần Nhà Trai).

⚠️ Link này có quyền sửa thiệp nên chỉ gửi riêng cho Cô Dâu / người nhà, không gửi cho khách mời.
