Đồng bộ lên Web & Gửi Cô Dâu tự sửa Lưu trên máy này

Để khi bạn hoặc Cô Dâu bấm Lưu, mọi thay đổi (địa chỉ, giờ, QR, ảnh album) sẽ tự đẩy lên GitHub và cập nhật cho tất cả khách mời trên mọi điện thoại:

  1. Chú rể mở trang tạo GitHub Token ↗ (chỉ làm 1 lần duy nhất).
  2. Đặt tên tùy ý (VD: thiep-cuoi), chọn Only select repositories → chọn thiep-cuoi-vannam-kimtien.
  3. Mục Repository permissions → Contents chọn Read and write → bấm Generate token và copy dán vào ô dưới đây:

Gửi link cấu hình riêng cho Cô Dâu

Cô dâu chỉ cần bấm link này trên Zalo → máy tự kết nối sẵn & mở thẳng tab Nhà Gái. Cô dâu sửa địa chỉ, giờ, QR, ảnh rồi bấm Lưu là tự đồng bộ lên GitHub cho mọi khách mời (tự gộp thông minh, không làm mất phần Nhà Trai).

⚠️ Link này có quyền sửa thiệp nên chỉ gửi riêng cho Cô Dâu / người nhà, không gửi cho khách mời.
